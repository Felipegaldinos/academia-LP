# BlackFit — landing page

Página de apresentação de academia com benefícios, galeria, depoimentos, oferta e localização.

## Recursos

Seções compostas pelos componentes de src/components/gym e navegação para a oferta de inscrição.

## Tecnologias

React, JavaScript e Vite. Consulte package.json para as dependências e versões declaradas.

## Executar localmente

Use Node.js e npm compatíveis com as dependências declaradas:

```sh
git clone https://github.com/Felipegaldinos/academia-LP.git
cd academia-LP
npm install
npm run dev
```

Abra o endereço exibido no terminal. `npm run build` gera a versão de produção. `npm run preview` permite visualizar esse build.

## Onde começar no código

- `src/App.jsx` — ponto de entrada para entender o projeto.

## Estado atual

A chamada de inscrição direciona para uma seção da página. Revise o atendimento e os dados de contato antes de apresentar o projeto como matrícula integrada.
